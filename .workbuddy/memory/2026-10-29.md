
## 登录页 UI 库从 antdv 迁到 Element Plus
- `src/views/login/index.vue`：`a-form/a-input/a-input-password/a-button` 全部换成 `el-form/el-form-item/el-input/el-button` + `ElMessage`/`FormRules`；
  规则改用 `prop` 绑定，`validate()` 用 `.catch(() => false)` 避免未捕获 Promise。
- 样式约定（用户明确要求）：**不写自定义类名样式，全部用 Tailwind 原子类**；仅保留 `@keyframes login-fade-up`（动画经 `animate-[...]` 任意值 + `motion-reduce:animate-none` 调用），
  渐变蒙版用 `bg-[linear-gradient(...)]`，验证码按钮用 `h-10 w-[108px] border-zinc-200 bg-zinc-50` 等原子类。
- 顺带补了两个让应用能起来的缺口：`src/utils/cookies.ts`（不再依赖已移除的 js-cookie，localStorage + `TOKEN_KEY`）、
  `guards/beforeEach.ts` 与 `stores/modules/user.ts` 缺失的 `getToken/setToken/removeToken` 导入。
